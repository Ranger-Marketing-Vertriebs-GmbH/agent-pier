# File Explorer UX Implementation Plan

> **For agentic workers:** Use superpowers:subagent-driven-development for independent tasks and review.

**Goal:** Implement the approved shared explorer inside the existing AgentPier shell.
**Architecture:** Preserve ExplorerWorkspace state, route ownership and operation hooks. Refactor presentation into focused toolbar, contextual actions, transfer disclosure and preview components. Keep the editor mounted and move its entry action into the preview through a portal.
**Tech Stack:** React, Vite, plain CSS, node:test, Playwright.
**Spec:** docs/superpowers/specs/2026-09-17-files-ux.md

## Global constraints

- Existing dark/orange shell unchanged. No backend changes or dependencies.
- Both global and session scope; matching German/English reactive catalogs.
- Keep operations, shortcuts, async ownership and dirty editor guards; <=600 lines per source/test.
- Isolated fixtures only; no real sessions or default tmux.

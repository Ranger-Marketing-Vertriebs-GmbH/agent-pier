# TUIUI Implementation Plan

> **For agentic workers:** Use superpowers:subagent-driven-development to implement assigned tasks. User authorizes autonomous execution; controller resolves routine design choices.

**Goal:** Usable local CLI workspace with multiple accounts, durable terminal sessions, mobile controls and Tailscale access.
**Architecture:** React/Vite static app served by Express, websocket PTY bridge to an isolated tmux server. Private profile storage. macOS service and owner-restricted Tailscale proxy.
**Tech Stack:** Node 22+, React, Vite, xterm.js, node-pty, tmux, ws, node:test, Playwright.
**Spec:** docs/superpowers/specs/2026-09-06-tuiui-design.md

## Global Constraints

- Work only in this new project; never alter unrelated sessions, credentials, projects or Serve endpoints.
- Default CLI approvals unchanged. No CLI installation and no model prompt that changes user files during testing.
- Secrets are local/private and never API response fields. Tests use temporary data and unique tmux sockets.
- Follow exact API interfaces in spec; small files with clear responsibility.
